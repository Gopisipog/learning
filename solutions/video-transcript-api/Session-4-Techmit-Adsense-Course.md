## Website Setup Steps

### Step 1: Update Name Servers
- Go to GoDaddy → My Products → DNS
- Update name servers according to your hosting provider
- Wait 5-6 hours for server propagation

### Step 2: SSL Certificate Installation
- Go to cPanel → SSL/TLS → SSL Sites
- Select your domain
- Enable "Sub domain + cPanel + mail" security
- Install certificate
- **Important:** Wait 7-8 hours for SSL to activate automatically

### Step 3: WordPress Installation
- Go to Software List → Select WordPress
- Choose HTTPS protocol (after SSL setup)
- Install WordPress

## WordPress Configuration

### Essential Pages to Create:
1. **Privacy Policy** - Auto-generated in WordPress, just publish
2. **Disclaimer** - Use disclaimer generator websites
3. **Contact Us** - Use Ninja Forms or Contact Form 7 plugin
4. **About Us**

### Theme Selection: Casual Theme
- Very minimalistic theme
- Used by well-known bloggers (e.g., Recharge Tricks)
- Increases AdSense approval chances by 20%
- Easy ad placement with sidebars

### Layout Configuration:
- Go to Theme Customizer → Layout
- Select layout with at least one sidebar
- Right sidebar recommended for normal websites
- AdSense needs space to place ads

### Widgets Setup:
- Go to Widgets → Primary Sidebar
- Add Custom HTML widget
- Add Search Bar widget
- Signals to AdSense that ad space is available

### Site Identity:
- **Never leave Site Title and Description empty**
- Fill in even random text if needed

### Menu Configuration:

**Footer Menu:**
- Privacy Policy
- About Us
- Contact Us
- Disclaimer

**Header Menu:**
- Categories
- Pages
- Set as "Main Menu" location

## Content Niches for AdSense Approval

### Recommended Niches (Highest Approval Rates):
1. **Health & Fitness**
2. **Jobs, Work & Education**
3. **Tech & Trading** (Foreign/international style, not Indian smartphone reviews)

### Avoid:
- APK websites
- Movie download content
- Content that tries to "trap" Google

### Important:
- Categories must match your actual content
- Mismatch causes "Navigation Voluntary Navigation Problem"

## Essential Plugins

### 1. Site Kit by Google (Most Important)
- Verifies website ownership
- Sets up Search Console automatically
- Connects Google Analytics
- Sends positive signal to Google AdSense
- **Always use Incognito window when setting up**

### 2. Insert Headers and Footers
- Required to implement Analytics tracking code
- Simple drag-and-drop solution
- No coding knowledge needed

### 3. WP Rocket (Cache Plugin)
- Reduces website loading speed
- Available as GPL version in course folder
- Automatically cleans cache files
- **Goal: Website speed under 3 seconds**

## Website Speed Optimization

### Check Speed Using:
- GTmetrix (gtmetrix.com)
- Target: Under 3 seconds loading time

### Why Speed Matters:
- Google wants fast-loading websites for ad views
- Slow speed = Policy violation
- Reduces approval chances

### Speed Tips:
- Use Casual theme (lightweight)
- Use optimized/compressed images
- ArticleFolk generates pre-optimized images
- WP Rocket caches files automatically

## Google Analytics Setup

1. Install Site Kit plugin
2. Connect Google account
3. Create Analytics account
4. Copy tracking code
5. Use "Insert Headers and Footers" plugin
6. Paste code in header section
7. Save and verify connection
