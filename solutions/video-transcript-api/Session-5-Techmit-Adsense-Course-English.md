## How to Upload Posts Properly

### Step 1: Use Classic Editor Plugin
- Install Classic Editor plugin from Appearance > Plugins > Add New
- This gives you a cleaner overview for posting

### Step 2: Proper Heading Structure
- **H1 Tag:** Already given as title (not mandatory if theme is good)
- **H2 Tags:** Very important - use for subheadings
- **H3 Tags:** Use for sub-subheadings
- Don't use H2 everywhere - use it strategically

### Step 3: Image Placement
- **Wrong:** Image at the top of post
- **Correct:** Image in the middle of your content
- Featured image shows on top automatically (especially with Jestar theme)

### Step 4: Alt Text (Very Important!)
- Never leave alternate text empty
- This signals Google Images
- Article Forge automatically adds alt text (90% of the time)

### Step 5: Categories
- Make proper categories
- **Mistake to avoid:** Don't select ALL categories for one post
- Select only relevant categories that target your content
- This signals Google that you're working genuinely

### Step 6: Tags
- Go to rapidtags.io > Tag Generator
- Enter your main keyword
- Copy the generated tags (Ctrl+V to paste)

### Step 7: Word Count
- **Minimum:** 500+ words per article
- Article Forge generates proper length articles

## Plagiarism Check

Before posting, always check plagiarism:
1. Go to **duplicatechecker.com**
2. Go to Plagiarism Checker option
3. Paste your content
4. Click "Check Plagiarism"

**Note:** Article Forge creates unique content. Even if it shows some plagiarism, it might be from your own websites. Google understands - up to 5% plagiarism is acceptable.

## Featured Images (Copyright-Free)

1. Go to Google Images
2. Search your keyword (e.g., "jobs in USA")
3. Click **Tools**
4. Click **Usage Rights** > Select "Creative Commons licenses"
5. Use these copyright-free images for featured images

## Creating Sitemap

### Requirements:
- **Minimum:** 20 posts
- **Recommended:** 30-32 posts

### Steps:
1. Install **Google XML Sitemap** plugin
2. Go to View Sitemap Detail
3. Download your sitemap
4. **Important:** Rename the file to just `sitemap.xml` (remove any numbers like sitemap3.xml)

### Upload to Hosting:
1. Login to cPanel
2. Go to File Manager
3. Navigate to your domain's directory
4. Upload the sitemap.xml file

### Verify Sitemap:
- Visit: `yourdomain.com/sitemap.xml`
- You should see all your post links listed

## Submit to Google Search Console

### Using SiteKit Plugin:
1. Go to SiteKit Dashboard
2. Go to Search Console
3. Login with same email used in SiteKit
4. SiteKit automatically verifies your property

### Submit Sitemap:
1. Go to Sitemaps section
2. Enter `sitemap.xml`
3. Click Submit
4. Status should show "Success" with discovered URLs

### Verify Indexing:
1. Copy a post permalink from your sitemap
2. Search it on Google
3. If it appears, your sitemap is successfully submitted
4. Your links are being crawled and ranked
