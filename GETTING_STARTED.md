```bash

```
**What it does:** Downloads all required packages

### Step 2️⃣: Start the App
```bash
npm start
```
**What it does:** Starts development server and opens browser

### Step 3️⃣: Enjoy!
- App opens at **http://localhost:3000**
- Explore questions
- Read code examples
- Learn React concepts

## 🐛 Troubleshooting

| Issue | Solution |
|-------|----------|
| Port 3000 in use | `PORT=3001 npm start` |
| Dependencies error | `npm cache clean --force && npm install` |
| Styles not loading | Clear browser cache |
| TypeScript errors | Check imports |
