## ⚡ 3-Step Quick Start

### Step 1: Preview (30 seconds)
```bash
npm start
```
Opens http://localhost:3000 - See your animation live!

### Step 2: Render (5-10 minutes)
```bash
npm run render
```
Creates `out/video.mp4` - Your final video!

### Step 3: Upload (2 minutes)
1. Go to YouTube Studio
2. Upload `out/video.mp4`
3. Set as "Shorts"
4. Publish!
