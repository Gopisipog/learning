## 🎨 Customization Options

### Change the Voice
Edit `generate-voiceovers.py` and change the VOICE variable:
```python
VOICE = "en-US-AriaNeural"  # Warm female voice
# or
VOICE = "en-GB-SoniaNeural"  # British female voice
# or
VOICE = "en-US-GuyNeural"   # Friendly male voice
```

### Create New Stories
Edit `story-generator.js` to create different stories:
- Different animals (dragons, dinosaurs, unicorns)
- Different themes (space, underwater, jungle)
- Different seasons (winter, summer, autumn)

### Adjust Music Volume
Edit `create-final-video.js` line with `volume=0.15`:
- Lower volume: `volume=0.10` (quieter music)
- Higher volume: `volume=0.25` (louder music)

### Change Video Duration
Edit `create-rhyme-video.js` and modify scene duration:
```javascript
duration: 5  // Change from 4 to 5 seconds per scene
```

## 🔧 Troubleshooting

**Video has no sound:**
- Check that audio files exist in `audio-files/`
- Verify `background-music.mp3` is present
- Re-run: `npm run final`

**Voiceover too quiet/loud:**
- Edit `create-final-video.js`
- Change `volume=1.5` to adjust voiceover volume

**Music too loud:**
- Edit `create-final-video.js`
- Change `volume=0.15` to lower value (e.g., 0.10)

**FFmpeg errors:**
- Make sure FFmpeg is installed
- Check all file paths are correct
- Try running commands individually
