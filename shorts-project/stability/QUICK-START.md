## 🎬 Create More Stories

```bash

npm run final                 # 5. Combine everything
```

## 🎨 Customize Your Story

**Change the story:**
Edit `story-generator.js` - modify the `storyScenes` array

**Change the voice:**
Edit `generate-voiceovers.py` - change the `VOICE` variable

**Adjust music volume:**
Edit `create-final-video.js` - modify `volume=0.15`
