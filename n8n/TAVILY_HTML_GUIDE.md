# Tavily Search to HTML - Complete Guide 🎨

Convert Tavily search results into beautiful, professional HTML files saved to your Desktop!

---

## 🎯 What This Does

**Input**: Search query via webhook
**Output**: Beautiful HTML file saved to `Desktop/TavilySearches/`

### Features
✅ **Beautiful Design** - Professional gradient UI with modern styling
✅ **Responsive** - Works on desktop, tablet, and mobile
✅ **AI Summary** - Highlighted summary section with yellow background
✅ **Search Results** - Clean cards with hover effects
✅ **Metadata** - Search depth, results count, timestamp
✅ **Clickable Links** - Direct links to source URLs
✅ **Score Badges** - Visual relevance scores
✅ **Auto-Save** - Saves to Desktop/TavilySearches folder

---

## 🚀 Quick Start

### Step 1: Import Workflow (30 sec)

1. Open n8n: http://localhost:5678
2. Click "Workflows" → "Import from File"
3. Select: `workflows/tavily-search-to-file.json`
4. The workflow is now imported!

---

### Step 2: Add Tavily API Key (1 min)

1. Click **"Tavily API Request"** node
2. Find **"JSON Body"** field
3. Replace `'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'` with your actual API key
4. Save

**Get API key**: https://tavily.com/ (free tier: 1,000 searches/month)

---

### Step 3: Activate & Test (30 sec)

1. Click "Save"
2. Toggle "Active" (top right)
3. Run test script:

```powershell
.\test-tavily-html.ps1
```

**Done!** Check `Desktop/TavilySearches/` for your HTML files!

## 🧪 Test Examples

### Simple Search
```powershell
$headers = @{ "Content-Type" = "application/json" }
$body = @{
    query = "What is quantum computing?"
    maxResults = 5
    searchDepth = "basic"
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://localhost:5678/webhook/tavily-search" `
    -Method Post -Headers $headers -Body $body
```

### Advanced Search
```powershell
$body = @{
    query = "Climate change solutions 2024"
    maxResults = 10
    searchDepth = "advanced"
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://localhost:5678/webhook/tavily-search" `
    -Method Post -Headers $headers -Body $body
```

## 🔧 Workflow Nodes

| Node | Type | Purpose |
|------|------|---------|
| **Webhook** | Trigger | Receives POST requests |
| **Extract Parameters** | Set | Parses query, maxResults, searchDepth |
| **Tavily API Request** | HTTP Request | Calls Tavily API |
| **Format Results as HTML** | Code | Generates beautiful HTML |
| **Save HTML to Desktop** | Code | Saves to Desktop/TavilySearches |
| **Respond to Webhook** | Response | Returns success message |

**Total**: 6 nodes
**Setup time**: 3 minutes

---

## 📊 Request Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `query` | string | "AI trends 2024" | Search query (required) |
| `maxResults` | number | 5 | Results count (1-10) |
| `searchDepth` | string | "basic" | "basic" or "advanced" |

## 🎨 Customization

### Change Save Location

Edit the **"Save HTML to Desktop"** Code node:

```javascript
// Current (saves to Desktop/TavilySearches)
const saveDir = path.join(homeDir, 'Desktop', 'TavilySearches');

// Save to Documents instead
const saveDir = path.join(homeDir, 'Documents', 'TavilySearches');

// Save to custom folder
const saveDir = 'C:/MyResearch/HTMLReports';
```

### Change Color Scheme

Edit the **"Format Results as HTML"** Code node CSS:

```css
/* Current: Purple gradient */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* Blue gradient */
background: linear-gradient(135deg, #4facfe 0%, #00f2fe 100%);

/* Green gradient */
```

## 🐛 Troubleshooting

### Issue: Files not saving

**Check**:
1. Desktop folder exists
2. n8n has write permissions
3. Check workflow execution log

**Solution**:
```powershell
# Check if folder exists
Test-Path "$env:USERPROFILE\Desktop\TavilySearches"

# Create manually if needed
New-Item -Path "$env:USERPROFILE\Desktop\TavilySearches" -ItemType Directory
```

### Issue: HTML looks broken

**Cause**: Browser compatibility or CSS not loading

**Solution**: Open in modern browser (Chrome, Firefox, Edge)

### Issue: API key error

**Solution**: See [TAVILY_API_TROUBLESHOOTING.md](TAVILY_API_TROUBLESHOOTING.md)
