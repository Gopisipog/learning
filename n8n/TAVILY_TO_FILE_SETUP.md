# Tavily Search to Text File - Setup Guide

Simple workflow to search with Tavily API and save results to a local text file.

## 🎯 What This Workflow Does

```
1. Receive search query via webhook
   ↓
2. Search with Tavily API
   ↓
3. Format results as text
   ↓
4. Save to local .txt file
   ↓
5. Return success response
```

**Result**: A formatted text file with search results saved locally!

---

## ⚡ Quick Setup - 3 Steps

### Step 1: Import Workflow (1 min)

1. **Open n8n**: http://localhost:5678
2. **Import workflow**:
   - Click "Workflows" → "Import from File"
   - Select: `workflows/tavily-search-to-file.json`
   - Click "Open"

---

### Step 2: Add Tavily API Key (1 min)

1. **Click "Tavily API Request" node** (the HTTP Request node)

2. **Find the "JSON Body" field**

3. **Replace `'tvly-YOUR_API_KEY'`** with your actual Tavily API key:
   ```json
   {
     "api_key": "tvly-abc123xyz...",
     "query": "...",
     ...
   }
   ```

4. **Save** (click outside the node)

**Get Tavily API key**: https://tavily.com/ (free tier: 1,000 searches/month)

---

### Step 3: Activate & Test (1 min)

1. **Save workflow**: Click "Save" button
2. **Activate**: Toggle "Active" switch (top right)
3. **Test it!** (see below)

### Option 1: Using Postman

1. **Create POST request**:
   ```
   POST http://localhost:5678/webhook/tavily-search
   Content-Type: application/json
   ```

2. **Add body**:
   ```json
   {
     "query": "Latest AI trends 2024",
     "maxResults": 5,
     "searchDepth": "basic"
   }
   ```

3. **Click "Send"**

4. **Expected response**:

   ```json
     "data": {
       "query": "Latest AI trends 2024",
       "resultsCount": 5,
       "answer": "AI in 2024 is characterized by...",

       "filePath": "/path/to/file.txt",
       "timestamp": "2024-11-25T10:00:00.000Z"

   }
   ```

---

### Option 2: Using cURL

```bash
curl -X POST http://localhost:5678/webhook/tavily-search \
  -H "Content-Type: application/json" \
  -d '{
    "query": "What is quantum computing?",
    "maxResults": 3,
    "searchDepth": "advanced"
  }'
```

---

### Option 3: Using PowerShell

```powershell
$body = @{
    query = "Climate change solutions"
    maxResults = 5
    searchDepth = "basic"
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://localhost:5678/webhook/tavily-search" `
  -Method Post `
  -ContentType "application/json" `
  -Body $body
```

## 📋 Request Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `query` | string | "AI trends 2024" | Search query |
| `maxResults` | number | 5 | Number of results (1-10) |
| `searchDepth` | string | "basic" | "basic" or "advanced" |

## 📁 Where Files Are Saved

Files are saved in the **n8n default directory**:

### Windows:
```
C:\Users\YourUsername\.n8n\
```

### Linux/Mac:
```
~/.n8n/
```

### File naming format:
```
tavily-search-{query}-{timestamp}.txt
```

**Examples**:
- `tavily-search-latest-ai-trends-2024-1732531200000.txt`
- `tavily-search-who-is-elon-musk-1732531300000.txt`
- `tavily-search-python-tips-1732531400000.txt`

## 🔧 Workflow Nodes

| Node | Type | Purpose |
|------|------|---------|
| **Webhook** | Trigger | Receives POST requests |
| **Extract Parameters** | Set | Parses query, maxResults, searchDepth |
| **Tavily API Request** | HTTP Request | Calls Tavily API |
| **Format Results** | Code | Formats API response as text |
| **Write to File** | Code | Saves results to .txt file using Node.js fs |
| **Respond to Webhook** | Response | Returns success message |

## 🎨 Customization Options

### Change File Location

Edit the **"Write to File"** Code node:

```javascript
// Current (saves to ~/.n8n/ directory)
const dirPath = path.join(homeDir, '.n8n');
const filePath = path.join(homeDir, '.n8n', fileName);

// Custom location (absolute path)
const dirPath = 'C:/MyFiles';
const filePath = path.join('C:/MyFiles', fileName);

// Or save to Desktop
const dirPath = path.join(homeDir, 'Desktop', 'TavilySearches');
const filePath = path.join(homeDir, 'Desktop', 'TavilySearches', fileName);
```

### Change File Format

Edit the **"Format Results"** Code node to change the text format:

```javascript
// Add more details
textContent += `   Published: ${result.published_date || 'N/A'}\n`;

// Change formatting
textContent += `### ${index + 1}. ${result.title}\n`;
```

### Add More Search Options

Edit the **"Tavily API Request"** node JSON body:

```json
{
  "api_key": "tvly-YOUR_API_KEY",
  "query": "...",
  "search_depth": "advanced",
  "max_results": 10,
  "include_answer": true,
  "include_images": true,
  "include_domains": [],
  "exclude_domains": []
}
```

## 🐛 Troubleshooting

### File not created
- Check n8n has write permissions
- Look in `~/.n8n/` or `C:\Users\YourUsername\.n8n\`
- Check workflow execution log for errors

### Tavily API error
- Verify API key is correct (starts with `tvly-`)
- Check you haven't exceeded quota (1,000 free searches/month)
- Verify at https://tavily.com/

### No results returned
- Try different search query
- Increase `maxResults`
- Use `searchDepth: "advanced"`

### Webhook not responding
- Make sure workflow is **Active**
- Check URL is correct: `http://localhost:5678/webhook/tavily-search`
- Verify n8n is running
